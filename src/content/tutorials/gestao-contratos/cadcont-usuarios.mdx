# Usuários do Contrato

![Imagem 1 - Cadastro de Contratos: Usuários](/tutorials/gestao-contratos/cadcont-usuarios/01.png)

O usuário que cadastrou o contrato já aparecerá listado (1). Para incluir novos usuários, clique no botão "Adicionar" (2).

![Imagem 2 - Cadastro de Contratos: Usuários](/tutorials/gestao-contratos/cadcont-usuarios/02.png)

Nos campos seguintes, acrescente os dados necessários para o cadastro de novos usuários.

Usuário\*: informe o CPF (1) ou o nome (2) do usuário que será incluído. O novo usuário também pode ser localizado por meio da lupa de pesquisa do respectivo campo (3).

Perfil\*: selecione o perfil a ser atribuído ao novo usuário.

Para finalizar a inclusão, clique no botão "Confirmar" (4).

Repita esses procedimentos para incluir mais usuários.
