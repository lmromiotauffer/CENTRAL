# Acessar a funcionalidade Empenho

Para cadastrar os empenhos vinculados ao contrato, use este guia como referência:

Clique na aba "Empenho".

![Imagem 1 - Cadastro de Contratos: Empenho](/tutorials/gestao-contratos/cadcont-empenho/01.png)

Para incluir um novo empenho, clique no botão "Adicionar".

![Imagem 2 - Cadastro de Contratos: Empenho](/tutorials/gestao-contratos/cadcont-empenho/02.png)

No campo "Empenho\*" (1), informe o número do empenho a ser cadastrado e depois clique no botão "Confirmar" (2).

Repita esse procedimento para incluir mais empenhos.

![Imagem 3 - Cadastro de Contratos: Empenho](/tutorials/gestao-contratos/cadcont-empenho/03.png)

Após incluir todos os empenhos, clique no botão "Salvar".

![Imagem 4 - Cadastro de Contratos: Empenho](/tutorials/gestao-contratos/cadcont-empenho/04.png)
