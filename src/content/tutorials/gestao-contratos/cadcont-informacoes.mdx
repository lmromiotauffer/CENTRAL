# Informações do Contrato

![Imagem 1 - Cadastro de Contratos: Informações](/tutorials/gestao-contratos/cadcont-informacoes/01.png)

Preencha as seções conforme os campos do sistema.

## Reajustamento
Data-base\*: informe a data-base de reajustamento.

Data de referência\*: informe a data de referência.

Periodicidade\*: este campo vem previamente preenchido como "12" (meses), atendendo a disposições normativas, e não deve ser alterado.

Reajustar por: este campo vem previamente selecionado como "Grupo" e deve ser alterado conforme o critério de reajustamento a ser adotado.

![Imagem 2 - Cadastro de Contratos: Informações](/tutorials/gestao-contratos/cadcont-informacoes/02.png)

## Informações adicionais
Periodic. cronograma\*: este campo vem previamente preenchido como "Mensal".

Os demais campos da seção "Informações Adicionais" e os campos da seção "Termo de Recebimento" não devem ser preenchidos no momento do cadastramento do contrato.

![Imagem 3 - Cadastro de Contratos: Informações](/tutorials/gestao-contratos/cadcont-informacoes/03.png)

Após o preenchimento de todos os campos obrigatórios e dos demais que forem pertinentes, clique no botão "Salvar".
