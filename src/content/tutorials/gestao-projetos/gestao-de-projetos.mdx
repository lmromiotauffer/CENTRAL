# Gestão de projetos

No menu do SINFRALOG, acesse "05.Gestão de Projetos" e abra a tela inicial do módulo.

![Imagem 1 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/27.png)

## Cadastro do projeto

No menu superior, selecione “Projetos” (1). Depois, clique em "+ Novo Projeto" (2) para abrir a página de cadastro.  
Preencha os campos de acordo com as instruções:

Código: Preenchido Automaticamente;

Número do Processo: Formato de busca do SIGADOC, exemplo: SINFRA-PRO-2025/00000. Ou para projetos antigos, numeração vigente na época.

Data do Protocolo: Data do SIGADOC e não a data do documento externo capturado ou da solicitação do protocolo.

Setor: Clique no ícone de seta para baixo para exibir a lista de opções.

Nome: Seguir modelo para cada tipo de projeto, fazer uma busca antes. Aqui estão alguns modelos:

- MT-000 Ponte de Concreto Rio Cuiabá PT00000
- MT-000 Pavimentação 100,00km
- MT-000 Restauração (Lote 1) 30,50km (Quando houver lotes)

Para consultar projetos já cadastrados, use a funcionalidade de consulta do módulo.

Descrição do Objeto: Neste campo, informe uma breve descrição que resuma o objeto do projeto.

Dimensão:

Unidade Medida:

- Rodovia: km
- Ponte: m
- Edificação: m2

Programa Governo: Apenas se for contemplado, selecione uma das opções, clicando no ícone de seta para baixo, (caso não tenha, solicite cadastro via GLPI).

Categoria: Clique no ícone de seta para baixo para exibir a lista de opções.

Se a categoria necessária não estiver disponível, cadastre-a antes de continuar.

Tipo de Serviço: Clique no ícone de seta para baixo para exibir a lista de opções.

Se o tipo de serviço necessário não estiver disponível, cadastre-o antes de continuar.

Origem: Clique no ícone de seta para baixo para exibir a lista de opções, (caso não tenha, solicite via GLPI)

Empresa Projetista: Para pesquisar, informe pelo menos 3 caracteres.

Responsável Técnico: Para pesquisar, informe pelo menos 3 caracteres ou o CPF. Em caso de diversos projetistas, conferir qual é o principal.

Se o responsável técnico ainda não estiver cadastrado, cadastre-o antes de continuar.

Número da ART:

Data de Validade ART: Conferir ART em: [https://www.crea-mt.org.br/portal/art/consulta-registro-art/](https://www.crea-mt.org.br/portal/art/consulta-registro-art/)

Localização do documento físico: Copie o endereço da pasta de rede onde o projeto está armazenado.

Observação:

Fases do Projeto: Selecione apenas a fase que corresponde ao projeto a ser cadastrado

Orçamento: Preenchido pelo módulo de orçamento.

Versão: Preenchida pelo módulo de orçamento.

Valor do Orçamento Calculado: Preenchido pelo módulo de orçamento.

Data Base do Orçamento Calculado: Preenchido pelo módulo de orçamento.

Valor do Orçamento Informado: Valor registrado no Volume 4 e no Termo de Aprovação do Projeto

Data Base do Orçamento Informado: Data registrada no Volume 4 e no Termo de Aprovação do Projeto

Coordenadas Iniciais e Coordenadas Finais: Preencha caso o projeto não seja de um ativo do Estado. Para obras pontuais repita as mesmas coordenadas.

Depois de preencher todos os campos obrigatórios clique em “Salvar” no final da página.

Agora o sistema vai liberar novas abas de cadastro do projeto

![Imagem 2 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/02.png)

## Cadastro de ativos

Clique em “2 Ativos”(1), nessa seção você poderá buscar e cadastrar os ativos pontuais. Informe pelo menos 3 caracteres para pesquisar o ativo (2) e então clique em “Incluir” (3).

![Imagem 3 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/03.png)

Nessa seção você poderá cadastrar os ativos dos trechos de rodovia. Para iniciar o cadastro clique em “Coordenadas” (1) e então clique em “+ Nova Coordenada” (2).  
  
Agora preencha as coordenadas iniciais e finais e clique em “consultar” (2).

![Imagem 4 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/04.png) ![Imagem 5 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/05.png)

IMPORTANTE!

- Caso o projeto possua mais de 1 rodovia, você deverá repetir esse processo para cada uma delas separadamente.
- O sistema identifica automaticamente a rodovia mais próxima da coordenada informada. Por isso, se a coordenada estiver localizada mais próxima de outra rodovia (1), como no exemplo abaixo, em que se tenta cadastrar a Rodovia Azul, mas a coordenada está mais próxima da Rodovia Verde, o sistema gerará um erro. Para resolver, acesse a Central Infra 2.0, localize uma nova coordenada que corresponda corretamente à rodovia desejada (2) e refaça o cadastro.

![Imagem 6 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/06.png)

Para localizar uma nova coordenada na Central Infra 2.0, aproxime o mapa com o máximo de zoom  
  
possível sobre o ponto desejado. Em seguida, clique no ícone “xyz” (1), depois selecione o ícone de "localização" (2) e, por fim, clique próximo ao final do segmento da rodovia que está sendo cadastrado (3). As coordenadas do ponto selecionado serão exibidas no formato GMS, no campo DMS (4).

![Imagem 7 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/07.png)

IMPORTANTE!

- Caso um novo projeto precise de cadastro de um novo ativo, seja ele Pontual ou Trecho, favor solicitar através da ficha de cadastro a Unidade de Gerenciamento de Projetos - UNIGEP/SINFRA (abaixo modelo)

![Imagem 8 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/08.png)

## Cadastro dos analistas

Para inserir um analista neste projeto, clique em “Analista” (1) e depois “ + Novo Analista ” (2).

![Imagem 9 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/09.png)

Agora informe o nome do analista, e clique em “Consultar” (1), depois clique no ícone de circulo (2) para selecionar e depois clique em “Salvar” (3).

![Imagem 10 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/10.png)

Caso não encontre o Nome do Analista desejado, será necessário abrir um chamado no GLPI para que ele seja adicionado no Módulo de Projetos.

Aparecerá novos campos para preenchimento na parte de baixo da tela. Preencha os campos conforme instruções abaixo:

Número do Processo: Formato de busca do SIGADOC, exemplo: SINFRA-PRO-2025/00000. Ou para projetos antigos, numeração vigente na época.

Descrição:  
Checklist: Clique no ícone de seta para baixo (1) e selecione o checklist desejado e depois clique em salvar (2)

## Análise do projeto

Para iniciar a análise do projeto, clique em “Projeto” (1), e, em seguida, “Proj. Executivo” (2). A tela com o checklist de análise será exibida. Clique no ícone de menu (3) e selecione a opção “Editar” (4).

![Imagem 14 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/14.png)

Siga as instruções abaixo:

1. Resposta: Clique no ícone de "círculo", para selecionar a opção desejada;
2. Solicitação/Justificativa: Campo destinado ao registro de justificativas e à inclusão de imagens, quando necessário.

![Imagem 15 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/15.png)

Após o preenchimento completo do checklist, para realizar o deferimento ou indeferimento, é necessário preencher as informações localizadas ao final do formulário:

(1) Identificação do analista: Este campo é destinado ao preenchimento das informações do analista responsável pela análise.

(2) Identificação do Supervisor: Este campo é destinado ao preenchimento das informações do superintendente responsável pelo setor.

(3) Descrição da análise:

(4) Conclusão:

(5) Deferir: Utilizada quando o projeto atende aos critérios e está apto para aceitação..

(6) Indeferir: Utilizada quando o projeto não atende aos requisitos necessários para aceitação.

IMPORTANTE!

Após a seleção das opções “Deferido” ou “Indeferido”, não será mais possível realizar alterações no checklist.

![Imagem 16 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/16.png)

Para gerar o Relatório de Análise, após selecionar “Deferido” ou “Indeferido”, clique no ícone de menu (1) e, em seguida, em “Download Relatório de Análise” (2). O arquivo será baixado automaticamente em seu computador no formato Word.

![Imagem 17 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/17.png)

Ao final da página, estão disponíveis as opções “Fechar” (1) e “Salvar” (2). A opção Fechar encerra o preenchimento do checklist; no entanto, antes de utilizá-la, é importante certificar-se de que todas as informações foram devidamente salvas. Já a opção Salvar permite registrar todas as informações inseridas no checklist até o momento, garantindo que nenhum dado seja perdido durante o processo de preenchimento.

![Imagem 18 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/18.png)

## Consulta de projetos

Para acessar a página de consulta, no menu superior, clique em “Projetos” (1)

![Imagem 19 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/19.png)

Clique em “Consultar” (2) sem preencher qualquer campo. Serão apresentados todos os projetos, mas a análise de como as informações são preenchidas pode auxiliar nas próximas consultas.

Para uma pesquisa mais específica, preencha os campos que considerar necessários, conforme instruções:

Código do Projeto: Número de contagem do Sinfralog.

Número do Processo: Formato de busca do SIGADOC, exemplo: SINFRA-PRO-2025/00000. Ou para projetos antigos, numeração vigente na época.

Descrição: Cada tipo de projeto segue um modelo. Aqui estão alguns deles:

- MT-000 Ponte de Concreto Rio Cuiabá PT00000
- MT-000 Pavimentação 100,00km
- MT-000 Restauração (Lote 1) 30,50km (Quando houver lotes)

Ativo(s) do Projeto: Apenas para ativos pontuais, pesquise o código de cadastro do Ativo.

Analista: Clique no ícone de seta para baixo e selecione uma das opções da lista.

Projetos sem Analistas: Marque a opção caso seja verdadeira.

Fase atual: Clique no ícone de seta para baixo e selecione uma das opções da lista.

Situação: Clique no ícone de seta para baixo e selecione uma das opções da lista.

Clique em “Consultar” (1) depois, para conferir as informações detalhadas, clique no botão de menu (2) e depois em “Editar” (3)

![Imagem 20 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/20.png)

## Cadastro de checklist

Para cadastrar um novo checklist, no menu superior, clique em “Cadastros” (1) e depois em “Checklist” (2).

![Imagem 25 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/25.png)

Agora clique em “+ Novo Checklist” (3), irá abrir uma tela para o cadastro.

![Imagem 26 - Gestão de projetos](/tutorials/gestao-projetos/gestao-de-projetos/26.png)

Preencha os campos de acordo com as instruções:

Descrição:

Situação: Clique no ícone de seta para baixo para exibir a lista de opções. Selecione “Ativo” para ficar disponível e “Inativo” ficará indisponível.

Tipo: Clique no ícone de seta para baixo para exibir a lista de opções. Selecione a opção desejada.

Depois de preencher todos os campos obrigatórios clique em “Salvar”.

Agora localize o checklist criado, clique no ícone de menu e, em seguida, em 'Gerenciar itens'. Uma nova tela será exibida para o cadastro dos itens do checklist. Clique em '+Novo item' para abrir a tela de cadastro.

Preencha os campos de acordo com as instruções:

Descrição:

Depois escolha umas das opções:

- Grupo
- Subgrupo
- Item

Repita o mesmo processo até inserir todos os itens desejados.

Agora retorne ao checklist, clique no ícone de menu e clique em “Publicar”, depois em “Salvar” para concluir.

ATENÇÃO: Após a publicação do checklist, não será mais possível realizar alterações.
