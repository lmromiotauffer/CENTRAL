Use este relatório para consultar o desempenho das empresas por medição, com as notas obtidas nos critérios de avaliação.

Parâmetros de consulta

Fornecedor: restringe o relatório a uma ou mais empresas.

Contrato: restringe o relatório a um ou mais contratos.

Medição: permite consultar uma medição específica pelo número.

Critérios: restringe o relatório a um ou mais critérios avaliados.

Período: limita o intervalo das medições consideradas no relatório.

![Imagem 1 - Relatório - Performance de fornecedores](/tutorials/gestao-fornecedores/relatorio-performance-de-fornecedores/01.png)

Emitir o relatório

Após definir os filtros e as opções de formatação, clique em "Visualizar" para emitir o relatório.

Confira o resultado gerado e, se necessário, ajuste os filtros para refinar a consulta.
