## Relatório: Fornecedores

Este relatório apresenta os fornecedores cadastrados no sistema.

(1) Parâmetros de consulta: preencha os campos que servirão como filtro para a emissão do relatório.

(2) Modelo de relatório: selecione o tipo de relatório.

(3) Formato: selecione o formato do arquivo digital do reltório.

(4) Visualizar: clique no botão "Visualizar" para gerar o relatório.
